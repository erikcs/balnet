This folder contains replication materials for the paper _balnet: Pathwise Estimation of Covariate Balancing Propensity Scores_.

Example data from [Wu et al. (2023)](https://doi.org/10.1126/sciadv.adi4123) is available at https://doi.org/10.5281/zenodo.20214890.

Please download the files individually using the "Download" button next to each file name. The "Download all" option adds an extra archive layer that must be manually extracted before use.

* `treated2008_conifer_X.csv.gz`: Covariates.

* `treated2008_conifer_W.csv.gz`: Treatment indicator.
