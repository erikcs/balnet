This folder contains replication materials for the paper _balnet: Pathwise Estimation of Covariate Balancing Propensity Scores_.

Example data from [Wu et al. (2023)](https://doi.org/10.1126/sciadv.adi4123) is available at https://doi.org/10.5281/zenodo.20214890.

You can download both files together using the "Download all" option which downloads a zip archive you need to unzip first before running the replication code. Note that in case you download the files individually depending on the browser used, an extra archive layer might be added which would require you to manually extract the file once before running the replication code which extracts the file a second time.

* `treated2008_conifer_X.csv.gz`: Covariates.

* `treated2008_conifer_W.csv.gz`: Treatment indicator.
